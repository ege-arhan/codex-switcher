# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People running ongoing local Codex and Claude coding tasks with multiple subscription accounts.

## Product Purpose
Manage account identity, verified remaining quota, safe switching and continuation from one desktop utility. Success: the user sees which account can work and whether automation is waiting or continuing.

## Operating Context
Existing React/TypeScript frontend inside Tauri on macOS, also built for Windows/Linux. This user's installation is macOS. Turkish and English interface. Native menu/tray and managed terminals.

## Capabilities and Constraints
Codex automatic switching only Plus and higher with verified quota; Claude only Pro/Max/Team/Enterprise. Wait on exhausted quota. Native Desktop continuation retains its own writer. Claude cloud chats remain account-bound. Preserve every functional setting and manual action; advanced details may be disclosed progressively. Credentials never become product copy, demo content or assets.

## Brand Commitments
Retain Codex Switcher name pending maintainer decision. User requests a simple understandable interface without AI-slop; seven selectable themes: Windows XP, Windows 7 and five others. Confirmed default: simple macOS. Additional chosen themes: Terminal, Paper, Nord and Mono alongside macOS. Themes change presentation, not behavior.

## Evidence on Hand
Existing live account data and runnable installed app. No invented claims or testimonials. Real identifiers only stay in the user's local UI, never in PR screenshots.

## Product Principles
Show identity and actionable remaining quota first. Keep automation state explicit. Keep active work intact. Hide advanced detail behind labeled controls without removing it.
